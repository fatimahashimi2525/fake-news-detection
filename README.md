# Fake News Detection

A machine learning and NLP project for detecting fake and real news using text classification techniques.

## Project Overview

Fake news can spread quickly through online platforms and make it difficult for people to identify reliable information.

In this project, different machine learning and deep learning approaches are used to classify news articles based on their text.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Natural Language Processing (NLP)
* TF-IDF
* BERT
* Google Colab

## Models

The project explores multiple machine learning and NLP approaches for fake news classification, including:

* Logistic Regression
* Multinomial Naive Bayes
* Support Vector Machine (SVM)
* Random Forest
* BERT

## Main Steps

1. Data collection
2. Data preprocessing and cleaning
3. Text preprocessing
4. Feature extraction using TF-IDF
5. Training machine learning models
6. Fine-tuning/evaluating BERT
7. Model evaluation
8. Comparing model performance

## Evaluation

The models are evaluated using classification performance metrics such as:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix
